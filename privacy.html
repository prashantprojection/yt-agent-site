Privacy policy

Last updated: 29 October 2026

yt-agent is a personal tool that only the owner of one YouTube channel uses, to manage that channel.

Data accessed

With the channel owner's OAuth consent, yt-agent uses the YouTube Data API and the YouTube Analytics API to read and manage that owner's channel, videos, playlists, comments and analytics.

Storage

OAuth tokens and any data retrieved are stored only on the owner's own computer. Nothing is sold, shared with third parties, or used for advertising.

Google API Services

yt-agent's use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements. yt-agent uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

You can revoke access at any time at myaccount.google.com/permissions.
